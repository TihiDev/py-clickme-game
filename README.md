# 🖱️ Py ClickMe Game

A very simple clicker game made while learning Python.

## 📋 Description

This is a beginner Python project.  
You get a simple window with a big button. Every time you click the button, your score increases.

Simple as that — perfect for learning the basics of Python and Tkinter.

## ✨ Features

- Simple and clean graphical interface
- Big clickable button
- Live score counter
- Score resets when you close the game
- Easy to understand code (great for beginners)

## 🛠️ Technologies

- **Python 3**
- **Tkinter** (built-in GUI)
